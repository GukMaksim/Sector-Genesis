# Sector Genesis

Sector Genesis is a sci-fi incremental "survivor-style" browser game built with Vue 3, Pixi.js, and TypeScript.

## Key Features
- Race-based evolution system.
- Automatic combat and weapon system.
- Persistent meta-progression.
- Challenging boss encounters at 5 and 10 minutes.
- Directional indicators for mineral and gas sources.
- Resource nodes respawn 60 seconds after exhaustion.

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
